## Project Description
This repository contains a simple C application that performs statistical analysis on an array of unsigned character data items. 

### Features
* Calculates basic descriptive statistics: Minimum, Maximum, Mean, and Median (rounded down to integers).
* Sorts data arrays in descending order (largest to smallest).
* Formats array data output for easy viewing via terminal.

### Files Included
* `stats.c` - Main execution logic and implementations of analytical functions.
* `stats.h` - Header file containing full function prototypes and Doxygen-formatted documentation.
* `README.md` - Repository overview and setup guidelines.
